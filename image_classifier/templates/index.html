Why MobileNetV2?
It's a tiny (~14 MB) Convolutional Neural Network designed for speed. It uses depthwise separable convolutions — a clever trick that achieves nearly the same accuracy as larger models while being 8× smaller and much faster. Originally designed to run on phones!
What is a Pretrained Model?
Researchers trained MobileNetV2 for weeks on 1.4 million images (ImageNet dataset). All that "knowledge" is stored in the model's weights. We simply load those weights and run new images through the same learned filters — no training needed on our end.
